# City College of Para-Veterinary Sciences — Website

Static website for City College of Para-Veterinary Sciences, Lakshbar Bajha, Pratapganj, Barabanki.

- `build/pages/` — page content (edit these)
- `build/build.py` — stitches shared header/footer into each page → `site/`
- `site/` — the published website (HTML, CSS, JS, images)

Build locally: `python3 build/build.py`, then open `site/index.html`.
Pushing to `main` deploys automatically to GitHub Pages.
